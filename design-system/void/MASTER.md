# VOID visual direction

The UI/UX skill's immersive experience and spacecraft HUD recommendations informed this original interface.

- Near-black/navy space; warm off-white typography; pale sage/cyan instrumentation; restrained warm stars.
- Full-viewport live universe. Thin rules, open spacing, one pale primary action. Avoid floating rounded cards.
- Manrope for large light-weight titles; Space Mono for instrumentation. System fallbacks keep the game usable if Google Fonts is unavailable.
- Keep instrumentation at the screen perimeter. A small projected world marker conveys selection; scanning state uses text and a progress bar as well as color.
- Explicit keyboard focus, semantic controls, menu focus management, reduced-motion CSS, and a dedicated small-screen message.
- Reference priorities: stable rendering, responsive flight, scale, deterministic generation, bounded streaming, then visual polish.
